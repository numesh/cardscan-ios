# Changelog

## 1.1.0 - 2026-10-09

- Added validated scanner configuration, presets, theme/icon/text overrides and UI slots.
- Added controls, confidence and timing tuning, brand/date policies and bounded fragment configuration.
- Added independent active-time timeouts, explicit confirmation and typed outcomes.
- Added masking, progress codes without card data and optional host validation.
- Added interactive demo settings, deterministic policy tests and complete configuration documentation.
- Preserved legacy launch APIs; documented timing and stale-evidence behavior changes.

## 1.0.0 - 2026-10-09

- Added AVFoundation and Vision card scanning with no third-party dependencies.
- Added Visa, Mastercard, and Amex number validation.
- Added expiry recognition, partial-number merging, scan feedback, torch, and tap-to-focus.
- Added the SwiftUI event-driven demo app.
- Added direct installation through Swift Package Manager.
